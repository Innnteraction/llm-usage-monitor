## 캡처와 마감 규칙

- 캡처 원본·비교 이미지·영상·부속 자료는 `.work/parity-captures/<단계>/<실행>/`에만 저장하고 Git에서 제외한다. 추적 문서는 캡처 ID·환경·판정만 기록한다.
- P0 기준 확보, P1 보정, P2 주요 상태·입력, P3/P4 플랫폼 검수 및 눈에 띄는 수정 전후에 사용자에게 원본 두 장과 좌우 비교를 공유한다. 실제 확보하지 못한 화면은 대체 제작하지 않는다.
- 같은 OS·배율·fixture·시각·테마·모드를 비교한다. 허구 데이터만 촬영하며 애니메이션은 같은 경과 시점을 비교한다.
- 구현 → 아키텍처 검사 → 관련 테스트·실행·캡처 → 기록 → 커밋. 중간 커밋과 단계 완료는 구분한다. 차단된 검증은 남기고 독립 작업은 진행한다.
- 메모리 목표는 표시 35 MiB·트레이 20 MiB다. P5 수용 전 main 병합·Electron 대체·배포 전환을 하지 않는다.
- 커밋 전 staged diff·민감정보 검사와 캡처 미포함을 확인한다. 마지막 trailer는 `Agent: OpenAI gpt-6-astra`다.
