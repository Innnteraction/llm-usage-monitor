# 단일 버전 선택 설치 마일스톤

- 목표: Node·Rust 중 하나를 선택하여 필요한 도구 설치부터 앱 실행까지 연결한다.
- 완료 모습: 관리 설치본 하나, 공통 자동 시작 하나, 안전한 업데이트와 버전 전환.
- 핵심 접근: OS 셸 진입점, 명시적 동의, 임시 빌드 후 교체, 공통 자동 시작 도구.
- 검증: 격리된 실패 시나리오와 실제 빌드·허구 데이터 실행. 실계정·재부팅 검수는 수동.

| 단계 | 결과물 |
| --- | --- |
| M1 | 환경 검사·비교·선택 진입점 |
| M2 | 동의 기반 빌드 도구 준비와 버전별 빌드 |
| M3 | 단일 설치·롤백·자동 시작과 앱 연결 |
| M4 | 한·영 README와 OS별 가이드 |
| M5 | 전환·실패·메모리 검증 기록 |

소스 ZIP에서도 시작한다. 개발 도구·캐시·인증은 제거하지 않는다. 자동 시작 변경은 선택한 설치본을 대상으로 한다. 신규 자동 시작 여부를 명시적으로 선택하고 업데이트는 기존 선택을 유지한다. 공개 패키지 배포·서명·공증·UI 통일 구현은 제외한다.
