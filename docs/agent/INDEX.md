# Agent 참조 인덱스

## 요약

이 문서는 Agent가 특정 작업을 시작할 때 상시 규칙 외에 어느 상세 계약을 읽어야 하는지 찾는 참조 문서다. 루트 AGENTS.md는 항상 적용하고, provider·quota·로컬 로그·인증을 다루는 작업에서만 provider 통합 계약을 추가로 읽는다. 인덱스에 없는 일회성 절차는 상시 지침으로 승격시키지 않는다.

`AGENTS.md`는 항상 적용한다. 아래 표에서 현재 작업과 일치하는 행만 읽고 연결된 문서를 절차의 정본으로 사용한다.

| 작업 단계 | 참조 | 반드시 얻어야 할 결과 |
| --- | --- | --- |
| provider quota 추가·수정 | [Provider 통합 계약](provider-integration.md) | CLI 소유권, 수집 source, 타입 mapping, stale·실패 표현과 테스트 경계를 확정한다. |
| 로컬 토큰 스캐너 추가·수정 | [Provider 통합 계약](provider-integration.md) | 스캔 범위, 증분·청크 파싱, 중복 방지와 partial 표시를 확정한다. |
| 자격증·인증·키체인 접근 경로 변경 | [Provider 통합 계약](provider-integration.md) | 읽기 전용이며 opt-in인지, 벤더 파일이 변경되지 않는지, 민감값이 노출되지 않는지 검증한다. |

문서와 구현이 다르면 실제 코드·타입·테스트를 먼저 확인하고 드리프트를 숨기지 않는다. 정본을 바꾸는 경우 관련 문서와 검증을 같은 작업에서 갱신한다.
