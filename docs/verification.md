# 검증 범위와 운영상 한계

## 자동 검증 범위

Windows x64에서 Node 타입 검사·lint·단위/통합 테스트, Rust 전체 대상 테스트,
양방향 공유 캐시·증분 인덱스·실행 잠금 교차 검증을 수행한다.
아키텍처 검사는 금지 의존·공개 경계 우회·미분류 모듈·정적 순환을 확인한다.
Rust 스킬 분석은 제한된 문법 해석이며 의미 기반 순환 전체를 보증하지 않는다.

설치 테스트는 임시 경로와 허구 도구·OS 등록을 사용해 신규 설치, Node↔Rust 전환,
같은 버전 갱신, 빌드·등록 실패 복구, 제거와 한글·공백 경로를 검증한다.
앱의 자동 시작 테스트는 임시 설치 폴더의 helper를 실제 실행한다.
실제 사용자 레지스트리·설치본·인증정보는 변경하지 않는다.

## 폴더 분리 검증 (2026-09-20, Windows x64)

| 검사 | 결과 |
| --- | --- |
| Node 타입 검사·lint | 통과 |
| Node 단위·통합 | 38개 파일, 265개 테스트 통과 |
| Rust 전체 대상 | 라이브러리 34개·앱 2개, 총 36개 통과 |
| Node↔Rust 캐시·증분 재사용 | 2개 통과 |
| Electron runtime E2E | 6개 통과: 시작·갱신·토큰·재열기·프로필 격리 |
| Node 경계·위반 주입 | 78개 소스, 위반 0건; 검사기 회귀 통과 |
| 통합 아키텍처 guard | 173개 모듈·확정 의존 270개, baseline 0건 |
| Windows 설치 | PowerShell 5.1 helper·entry 전환/복구·읽기 전용 환경 점검 통과 |
| Bash | 설치기·공통 helper 구문 검사 통과; macOS 실행 검증 아님 |
| 산출물 | Rust release 전체 bin, Electron 일반/설치용 패키징 성공 |

Git 추적 파일만 내보낸 임시 소스에서 `.work`, `node_modules`, `target`, Electron 산출물이
없는 상태로 시작했다. 한글·공백 경로에서 Node 준비·타입 검사·lint, Rust 전체 테스트와
앱 빌드, 교차 캐시 및 Electron 설치용 패키징을 확인했다. 개발 도구와 패키지 다운로드
캐시는 재사용했으므로 개발 도구가 없는 새 PC에서의 설치 검증을 뜻하지 않는다.

최초 Node 테스트에서 Electron 44의 지연 다운로드가 병렬 worker 사이에서 충돌했다.
앱 postinstall에서 런타임을 한 번 준비하도록 수정한 뒤 두 번째 새 소스 사본에서
잠금 파일 기반 설치·Node 265개 테스트·경계 검사·패키징을 통과했다.

기존 `.work` 파일 103개의 SHA-256이 작업 전후 같고 Git 추적 항목은 0건이다.
실제 관리 설치본·자동 시작 등록·인증정보는 이 검증으로 변경하지 않았다.

## 메모리 비교

2026-09-20 Windows x64에서 같은 허구 snapshot의 펼친 화면을 순차 실행했다.
준비 5초 뒤 5회 측정한 프로세스 트리 Working Set 합계는 다음과 같다.

| 구현 | 범위 (MiB) | 중앙값 (MiB) |
| --- | --- | --- |
| Node / Electron | 313.82–318.30 | 316.25 |
| Rust / GPUI | 55.04–55.04 | 55.04 |

공유 페이지 중복 합산이 가능하며 private bytes와 다른 지표다. 실계정 수집 부하는
포함하지 않았고 다른 PC·macOS·장시간 실행으로 일반화하지 않는다.
원시 결과와 캡처는 로컬 `.work`에만 보관하며 빌드·테스트 입력으로 사용하지 않는다.

## 남은 실기 검수와 위험

- macOS 설치 전환·LaunchAgent·실화면, Windows 실제 로그인/재부팅 자동 시작은 별도 수동 검수다. 원격 CI 결과도 로컬 검사 결과와 구분한다.
- CSS와 GPUI의 표시 계약 검증은 전체 픽셀·애니메이션 동등성을 보증하지 않는다.
- 깨끗한 PC의 도구 설치는 관리자 권한, 프록시, 다운로드 정책, 재부팅의 영향을 받는다. 공용 개발 도구는 실패 시 자동 제거하지 않는다.
- macOS ad-hoc 서명은 공증이 아니다. Gatekeeper와 Xcode 라이선스를 자동 우회하지 않는다.
- 강제 종료·전원 차단은 정상 오류 롤백과 다르다. 설치 backup·transaction 잔여물을 자동 삭제하지 않는다.
- Windows 실행 잠금 포트가 OS 예약 포트와 충돌할 수 있다. 패키징 파일 잠금 시 기존 설치를 유지하고 잠금 해제 후 다시 실행한다.
- GPUI 전이 의존성 `proc-macro-error2 2.0.1`의 향후 Rust 호환성 경고는 남아 있다.

- Electron Packager는 기본 공용 임시 폴더를 정리하므로 여러 checkout의 Node 패키징을 동시에 실행하면 충돌할 수 있다. 검증 중 이 충돌을 확인했고 순차 빌드는 통과했다.
- 일부 기존 전체 화면 E2E는 제거된 Tokens 버튼·과거 문구를 참조한다. runtime E2E는 현재 기본 표시로 수정했으며 나머지 시각 테스트의 전체 통과를 주장하지 않는다.
